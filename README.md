# EarthOnline Resources

面向 EarthOnline 的社区资源资料库。只维护资源知识、证据、获取方式和数据规范；核心游戏代码独立维护。

每个资源必须描述如何获取：直接收集、采集、挖掘或加工。加工获取需写明原料、设备和条件，例如提炼、蒸馏、过滤。组成允许化学式或混合物比例范围；未知属性可留空，不编造数值。

运行检查：

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
python3 tools/validate.py
```

`schema/resource.schema.json` 是结构契约。`resources/` 三个文件为待科学审核的起始示例，校验通过仅代表格式与内部引用有效。来源必须支持具体主张，AI 无法核实的内容进入待补证状态。

贡献通过 PR：格式校验 → 证据核查与 AI 辅助审查 → 维护者审核 → 游戏所有者选择版本。AI 审核尚未连接外部模型，目前提供人工审核模板。数据合并不等于游戏启用；核心仓按固定提交和校验和导入经所有者批准的资源包。

资源的真实名称与成分是公共资料；游戏内仍按玩家认知过滤显示。具体世界分布、储量和玩法参数由核心规则决定，不在本仓贡献范围。

贡献者须有权提交内容。新贡献数据以 CC0-1.0 提供；引用资料与外部文献保留各自许可，不将其整篇复制进仓库。校验代码以 MIT 许可提供。

当前上传连接不具备工作流权限，自动检查模板保存在 `ci-templates/github-actions-validate.yml`，尚未启用远端自动校验。维护者可在具备相应权限后将其放入 `.github/workflows/validate.yml`，再启用必需状态检查。目前先执行本地校验和负责人审核。
