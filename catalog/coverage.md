# 可居住星球资源覆盖清单

本清单是**待研究范围**，不是已经审核通过的资源，也不构成物种在任何星球上的投放承诺。资源条目必须逐项提供支持其名称、组成、形成/栖息、获取方式与相关数值的来源。未知数值保持未知。现有 `resources/` 只有水、天然水样、石英 3 个待审示例。

## 建立星球时必须覆盖的资源关系

| 领域 | 首批资料目标 | 生态与世界规则用途 |
| --- | --- | --- |
| 大气 | 氮、氧、二氧化碳、水汽及空气混合物 | 呼吸、温室效应、天气与燃烧条件 |
| 水圈 | 海水、淡水、雪、冰、地下水、湿地水 | 水量守恒、蒸发、降水、径流、可饮用性 |
| 岩石矿物 | 常见岩石、砂砾、黏土、石英、盐、铁铜矿物 | 地形、土壤来源、早期工具及长期资源链 |
| 土壤 | 不同质地及水分条件的土壤与沉积物 | 植被生长、侵蚀、洪水和农耕条件 |
| 陆地生产者 | 热带、温带、寒带、草原、荒漠、苔原中的实际植物和地衣 | 生态起点、食物、木材、种子传播 |
| 陆地消费者 | 对应生态中的实际草食、杂食和捕食动物及昆虫 | 食物网、迁徙、竞争和人类观察 |
| 淡水生物 | 河流、湖泊、湿地中的水生植物、藻类、无脊椎动物和鱼类 | 饮水地生态、食物网、洪水扩散 |
| 海洋生物 | 潮间带、珊瑚礁、远洋和深海中的初级生产者与消费者 | 海洋食物网及沿海资源 |
| 分解者 | 真菌及微生物类群 | 有机物分解与养分循环；首版疾病传播仍不启用 |
| 自然能量 | 太阳辐射、风、水流、地热和可燃生物质的证据与条件 | 可发现、可利用的能量来源，不视作可采矿物 |

## 分类依据

- 陆地生态：NASA [Mission: Biomes](https://science.nasa.gov/kids/earth/mission-biomes/)；细分地表覆盖参考 [MODIS IGBP](https://www.earthdata.nasa.gov/s3fs-public/2025-04/MCD12_User_Guide_V6.pdf)。
- 河流、湖泊、湿地及地下水：USGS [Water Cycle](https://www.usgs.gov/water-science-school/water-cycle)。
- 海岸、珊瑚礁、远洋和深海：NOAA [Marine Sanctuary Ecosystems](https://sanctuaries.noaa.gov/visit/ecosystems/)。
- 土壤分类：FAO [World Reference Base](https://www.fao.org/soils-portal/soil-survey/soil-classification/world-reference-base/en)。
- 生物学名与分类核对可使用 GBIF [Species API](https://techdocs.gbif.org/en/openapi/v1/species)；出现记录不单独证明生态适应性、食性、获取或安全性。

## 收录原则

1. 每类生态先形成能自我维持的生产者、消费者、分解者与水土条件组合，再扩展物种数量。
2. 原始数据和游戏中的分布概率、数量、产量分开；后者由私有世界规则管理。
3. 同一真实物种只保留一个稳定 ID，通过多个生态标签表示其可能分布；同义名、翻译名或生长阶段不复制成不同物种。
4. 对大型矿床形成、物种栖息和物质转化分别记录时间尺度。资料没有依据时不得用 AI 猜测填补。
5. 上线前每个启用的条目都须通过科学证据与许可核查，形成固定版本，供私有游戏仓按版本导入。
